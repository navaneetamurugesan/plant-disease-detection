# 🌿 GreenLeaf: AI-Powered Plant Disease Detection & Fertilizer Recommendation

This project is a Flask-based web app that uses deep learning to detect plant diseases from uploaded images and recommends suitable fertilizers. It also includes Docker support for easy deployment.

## 🚀 Features

- Upload a plant image and detect diseases using a trained model
- Recommend fertilizers based on detected disease
- Simple UI for users
- Dockerized setup

## 🧠 Technologies Used

- Python
- Flask
- PyTorch or TensorFlow
- OpenCV
- Docker
- HTML/CSS (for frontend)
